## Completed

### Database (`supabase/migrations/20260924160000_league_foundation.sql`)

`piele.users`, `leagues` (deferred captain foreign key), `league_memberships` (nickname, full name, `invited_email`, no role column), `seasons`, `season_memberships`, `duties` (plan M17 lifecycle, one live duty per member/round/type), `media_assets`, `evidence_submissions`, `duty_evidence_links`, `feed_entries` and append-only `audit_events`. Row level security on every table keyed on transaction-local `piele.league_id`, `piele.auth_subject` and `piele.auth_email` settings; memberships are additionally readable through the caller's own account or a pending invitation for the caller's verified email. Round numbers are the round's position in the bundled schedule (1–21); no rounds table yet.

### API (`apps/api`)

- `app/league/auth.py`: Supabase token verification (JWKS with ES256/RS256, or HS256 with `SUPABASE_JWT_SECRET`), audience and issuer checked. New pinned dependency `pyjwt[crypto]==2.10.1`.
- `app/league/context.py`: one transaction per request; sets actor context, upserts the user, finds the active membership or claims one by verified `invited_email` (single use), then sets the league. `403 not_a_member` otherwise. Captain authority = `leagues.captain_membership_id`.
- `app/league/service.py`: members (list, add, set email), duties (create with Spoon default deadline, void, list with computed marks and derived `display`: open, overdue, under_review, completed, voided, pending_deadline), marks totals, evidence (reserve upload grant, publish submission after checking the stored object, decide a link, playback URL), feed. Every mutation writes its audit event and feed entry in the same transaction.
- `app/league/marks.py`: `floor(max(0, elapsed − paused) / 168 h)`, stopping at completion or season closure; unknown deadline and voided duties earn nothing.
- `app/league/storage.py`: Supabase Storage via REST with the service role key. Unverified against a live bucket (see open items).
- `app/league/bootstrap.py`: `uv run python -m app.league.bootstrap --captain-email …` creates league, captain, season and members from `app/data/league_members.json` (the Superbru list plus Schnetler, Anrich (Annas)).
- `app/routers/league.py`: `/v1/me`, `/v1/members`, `/v1/duties`, `/v1/duties/default-deadline`, `/v1/duties/{id}/void`, `/v1/marks`, `/v1/evidence/uploads`, `/v1/evidence`, `/v1/evidence/links/{id}/decision`, `/v1/evidence/assets/{id}/playback`, `/v1/feed`.
- Settings: `SUPABASE_JWT_SECRET`, `SUPABASE_SERVICE_ROLE_KEY`, `SUPABASE_STORAGE_BUCKET`, `EVIDENCE_*`. `.env.example` and README updated.

### Web (`apps/web`)

- `core/auth`: `AuthService` (supabase-js 2.99.0, Google OAuth and password sign-in/sign-up), `authInterceptor`, guards `signedIn`, `signedOut`, `memberRequired`. Pages `features/sign-in` (sign-in) and `not-a-member`. Sign-out on the profile page. Builds without a Supabase project skip sign-in.
- `core/league`: plan-shaped `Duty` model, extended `LeagueData` contract, `HttpLeagueData` (API client, direct Storage upload with the API's grant), `SampleLeagueData` rewritten with duties, marks, feed, captain actions; `marks.ts` for the sample league only. `RoundViewService` now derives reviews from pending evidence, season marks, round and season feed, and the member's league nickname.
- `core/competition/league-time.ts`: SAST formatting, relative times, `datetime-local` conversion.
- Duties page: `DutyCard` (status, deadline, marks with next threshold, evidence trail, Watch video, upload/record/void actions), `CreateDutyDialog` (captain; member, type, round, default or custom deadline, reason), `ReasonDialog` (void, accept, reject). Evidence dialog restyled and supports captain on-behalf recording with completion time.
- Captain page: pending evidence with accept/reject and self-review lock, team sheet with sign-in emails and add-member form.
- Home: duty card by display state, season house marks, `Feed` component with R{code}/Season toggle. Standings: house marks tab is season-wide from `/v1/marks`. Notifications flag uses the new deadline fields.
- `styles/ui.scss`: `.detail-dialog { margin: auto }` restores native centring that Tailwind's preflight margin reset had removed (the top-left bug); `.compact-dialog` variant.
- `angular.json`: initial budget warning raised 500 kB → 650 kB for supabase-js (initial 604 kB).
- Docs: root README, `docs/production.md` step 4 (Auth providers, redirect URLs, bucket, bootstrap), both CLAUDE.md files.

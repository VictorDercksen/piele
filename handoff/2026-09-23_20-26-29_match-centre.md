# Match centre: Rounds page removed, match details page with teamsheets, prices and forecast

Request: Remove the Rounds page. "Enter the match centre" on the home hero opens the featured fixture on a match details page with the latest teamsheets, bookmaker prices, weather and related information. Plan approved with three decisions: show odds (information only), forecast only inside the week before kickoff, cache provider responses.

## Completed

Frontend (apps/web):
- Deleted `features/rounds`. Removed its route and both nav entries. Desktop nav has five items, mobile nav four.
- New lazy route `/match/:fixtureId` (`features/match/`). The page keeps the URL, the selected round and the featured fixture consistent: a deep link aligns the round with its fixture, changing the round moves to that round's featured fixture, an unknown fixture returns home. It reconciles once on creation because a deep-linked page is created after its NavigationEnd.
- Hero button navigates to `/match/<featured id>`. The fixture ribbon navigates when the match page is showing and features otherwise. The notifications round item opens the match centre.
- The house pick deadline banner (with the Superbru link on the current round) moved to the match page. The schedule-source note moved to More.
- `CompetitionService.locate(fixtureId)` finds a fixture and its round. `core/api/match-centre.models.ts` mirrors the API contract; `MatchCentreService.centre()` wraps `httpResource`.
- Match page sections: header with club crests, kickoff SAST, venue; teamsheets 1 to 23 per side with captain marks; prices (home, draw, away, handicap, bookmaker, information-only note); kickoff forecast (temperature, feels like, rain chance, wind, gusts). Each section shows copy for `not_published`, `too_early`, `past`, `not_covered` and `unavailable`. Whole-page states: API not configured, API unreachable with retry, loading.

API (apps/api):
- `GET /v1/matches/{fixtureId}` (`app/routers/matches.py`, `app/matchcentre/service.py`). 404 for unknown fixtures. Three sections fetched in parallel threads, each with its own status.
- `app/data/urc_fixtures.json` is written by `apps/web/scripts/import-urc.mjs` alongside the TypeScript schedule. Club and stadium catalogues (20 grounds with coordinates) in `app/matchcentre/catalogue.py`.
- Providers: `teamsheets.py` (URC GraphQL `matchstats(match_id:)`, queried from three days before kickoff), `odds.py` (The Odds API: sport discovered by title, h2h + spreads, one region, most recently updated bookmaker, requested only inside eight days of kickoff), `weather.py` (Open-Meteo hourly at the hour nearest kickoff, only inside seven days).
- Cache: `external_snapshots` table (Alembic revision `0001_external_snapshots`) with TTLs sports 24 h, odds 6 h, weather 3 h, teamsheets 6 h published / 20 min pending / 10 min failed. Stale snapshots are served when a provider fails. In-memory fallback when DATABASE_URL is unset.
- Settings: `ODDS_API_KEY`, `ODDS_SPORT_KEY`, `ODDS_REGIONS`, `URC_GRAPHQL_URL`, `WEATHER_API_URL`, `EXTERNAL_TIMEOUT_SECONDS`. httpx is now a runtime dependency. The odds key is in the git-ignored `apps/api/.env` only.

Docs: README.md, apps/api/README.md, apps/api/CLAUDE.md, fixtures/README.md (teamsheet verification note), apps/api/.env.example.

## Unresolved

- Provider hosts (unitedrugby.com, the-odds-api.com, open-meteo.com) are blocked from this container, so no provider was exercised live. The URC lineup fields in `teamsheets.QUERY` are a best guess and must be confirmed with an introspection query (see fixtures/README.md). A rejected query shows as `unavailable`, never as an empty teamsheet.
- The Odds API sport key for the URC is discovered by title. If the free tier does not list the URC, prices show `not covered`; `ODDS_SPORT_KEY` overrides discovery.
- `ODDS_API_KEY` is not set on Vercel (api.vercel.com is blocked from this container). Add it to `piele-api` Project Settings > Environment Variables for Preview, then redeploy.
- Run `uv run --env-file .env.staging alembic upgrade head` against the staging Supabase project before relying on the cache in staging.
- `scripts/import-urc.mjs` was already outside Prettier's style before this change; untouched.

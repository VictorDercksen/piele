# Scoring pitch

Request: redesign the Match Centre scoring section as a rugby pitch (agreed through an HTML mockup), use the combined row style, hide the section until 10 minutes before kickoff, and open it with a smooth animation.

## Completed

- `features/match/scoring.ts`: new view model. `scoringView(fixture, section, now, kickoffUtc)` returns null until `SHOW_BEFORE_KICKOFF_MS` (10 minutes) before kickoff, and while the API reports `too_early`. Rows are placed to scale (12 px per minute, kickoff at the top try line, 40' on the halfway line, 80' at the bottom). Rows on one side never overlap and never cross the halfway line or the live-minute marker; earlier rows move up to make room. Pitch lines (22 m, dashed 10 m, halfway) sit at their metre positions mapped to minutes.
- `features/match/scoring-panel/`: new `ScoringPanel` component.
  - Summary row: club-colour blocks with crest and score at each end, and a timeline of the match between them (home events above the line, away below; try, kick and card markers; half time; live minute and unplayed part).
  - Combined rows: tries are full points-tab rows (+5/+7 block in club colour, player, minute and running score with the scoring side in bold); kicks and cards are slim tabs against the centre of the pitch. Short labels and no surnames on narrow containers.
  - Pitch: textured grass (inline SVG noise data URIs, allowed by the CSP's `img-src data:`), mowing bands, worn goalmouths, chalk lines via an inline SVG filter, posts on the try lines.
  - Closed by default. A tap anywhere on the closed panel opens it; once open, only the heading and summary close it. Visual cues: the top of the pitch peeks out under a fade, a "Tap to open the pitch" hint, and a hover state. The summary row is the keyboard control (`role="button"`, `aria-expanded`, Enter and Space). The closed pitch is `inert`.
  - Animation: height animated with the Web Animations API between measured heights (520 ms open, 420 ms close, ease-out); skipped under reduced motion.
- `match.page.ts`: `data` is now a `linkedSignal` that keeps the last match centre through a refresh of the same fixture. Before, each live poll rebuilt the data branch of the page, which would have closed the pitch every 30 seconds. `scoring` uses `LiveScoresService.clock` (new read-only signal) so the panel appears on time without a reload.
- Old timeline styles removed from `match.page.scss`.

## Notes

- Do not name classes `collapse` in components: Tailwind's utility of the same name sets `visibility: collapse` globally. The drawer is `.drawer`.
- The API still starts serving scores 15 minutes before kickoff (`PRE_KICKOFF`); the 10-minute rule is applied in the web view model.

# Kickoff forecast rain

## Request

Victor sent a screen recording of the kickoff forecast in light drizzle. The rain read as diagonal hatching, not rain. He asked for rain that looks like rain and for the effect to cost nothing noticeable on any device.

## Cause

- The rain was one `repeating-linear-gradient` of evenly spaced full-length lines. It read as a hatch pattern.
- It animated `background-position`, which repaints the layer every frame. Snow did the same.
- Four fact tiles used `backdrop-filter: blur(8px)` over the moving rain, so the blur was recomputed every frame.
- The drifting clouds carried `filter: blur(10px)`, and fog `blur(14px)`.

## Changes

- `weather-panel.html`: `.sky-precip` now holds a `.sky-fall` span.
- `weather-panel.scss`:
  - Precipitation is two SVG tiles of randomly placed streaks (or flakes for snow): a faint far layer and a brighter near one at different speeds. Streaks fade from tail to head.
  - The layers are `.sky-fall::before` and `::after`. Each is one tile taller than the panel and animates `transform: translate3d` by exactly the tile height, so the loop is seamless and runs on the compositor. `.sky-fall` sets the slant and is oversized by 160 px so its rotated corners stay outside the panel.
  - Pseudo-elements get `content` only in drizzle, rain, storm and snow, so other scenes create no layers. Clear skies no longer render the hidden cloud layer.
  - Rain: 10° slant, 0.62 s and 0.42 s per tile. Storm: 16°, faster and brighter. Drizzle: the rain tiles squashed to 55 % height at 6°, slower and dimmer. Snow: flake tiles at 8°, 14 s and 9 s.
  - Fact tiles use a solid `#00000047` tint instead of the backdrop blur.
  - Clouds and fog use softer gradient stops instead of `filter: blur`.
  - Removed `sky-rain` and `sky-snow` keyframes. Added `fall-far` and `fall-near`.
- Reduced motion is still covered by the global rule in `styles.scss`. The streaks then show still.

## Checks

- Chrome trace over 2 s with all five precipitation scenes on screen (scratch harness with the compiled SCSS):
  - Before: 723 paints, 2054 ms of raster work.
  - After: 0 paints, 0.7 ms of raster work, no style recalculation.
- Screenshots and a recorded clip of drizzle, rain (day and night), storm and snow: streaks cover the whole panel while falling, with no gaps at edges or seams.
- `npm run build` (Node 24.15; the container's Node 22.22.2 is below the CLI minimum): passes, no warnings.
- `npm test -- --watch=false`: 111 files, 557 tests passed.
- `npx prettier --check` on the weather panel: clean.
- e2e `match-centre`, `stadium-backgrounds`, `live-scoring` (port 4317): 12 passed.

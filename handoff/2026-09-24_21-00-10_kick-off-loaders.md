# Kick-off loaders

## Request

Make the loading screens and spinner less empty. The user reviewed four mockups (Floodlights, Club crest, Kick-off, Under lights; published as a private artifact) and chose Kick-off for the loading screens, with the Club crest option's arc for button spinners.

## Completed

- `shared/loader` (`app-loader`): now a spinning arc drawn in the current text colour (conic gradient with a ring mask). Same inputs (`size`, `label`, `showLabel`); default size is 18. Used in buttons and the More page's API check. Slows to 2.4 s per turn under reduced motion.
- `shared/ball-loader` (`app-ball-loader`): new. The URC ball hops and tumbles over a squashing shadow, with a visible caption; `role="status"` and `aria-label` carry the label. Motion stops under reduced motion. Used by the shell page loader, match centre loading and the claim page's team-sheet loading.
- Start-up screen (`src/index.html` and the `App` boot overlay): faint pitch lines (`public/assets/editorial/pitch-lines.svg`, fading out below halfway), the bouncing ball landing on the halfway line, "Kick-off", the PIELE wordmark and four rotating phrases. Both render the same markup; the CSS lives once in index.html's `<style>` (the CSP allows inline styles). The `.boot` rule was removed from `app.scss`.

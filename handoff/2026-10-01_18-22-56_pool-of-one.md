# Pool picks: a pool of one is a line, not a table

Recorded on 2026-10-01 in Africa/Johannesburg time. Branch `claude/pool-of-one`, from `master` at `88fe677`.

## Request

From a phone screenshot of the match page's Pool picks card after the member picked, before anyone else had: the card showed "Your pick · Stormers 6 · Edit", then a Member/Pick table with one row, "Victor Dercksen YOU · Stormers 6", and the scoring legend. The user found the state redundant and asked for a fix with screenshots.

## Cause

The API shows the pool to a member once their own pick is in (`_fixture_views` in `apps/api/app/league/service.py`: `visible = is_locked or mine is not None`). When nobody else has picked yet, the pool is the member's own pick again.

## Changes

1. **`poolOfOne`** (`features/match/picks-panel/picks-panel.ts`): true before kickoff when every visible row is the member's own. `showPool` is now false in that state, so the dropdown has no chevron, no table, no split and no scoring legend.
2. **A line in place of the pool** (`picks-panel.html`, `.scss`): under the member's strip, with the Lucide `users` icon: "You're the first in. The pool's picks show here as the others make theirs, and at kickoff." Muted, 12 px, like the form's "Make your pick" note.
3. **Tests.**
   - `picks-panel.spec.ts`: the pool-of-one case expects the strip with Edit, the note, and no table, split, chevron or legend; after Edit the note is gone.
   - `e2e/superbru.spec.ts`: after the first pick the journey expects the note and no table, split or chevron; the test is renamed to match.

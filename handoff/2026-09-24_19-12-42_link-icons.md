# Link icons replace emoji glyphs

## Request

Replace the emoji-style glyphs after link text (for example "Current round ↗", which iOS renders as an emoji) with appropriately styled ng-icons, and remove all emojis from the application.

## Completed

- Installed `@ng-icons/core` and `@ng-icons/lucide` 36.0.0 (pinned, matching Spartan's icon stack).
- Added the shared `.link-icon` style in `src/styles/ui.scss` (1.3em, trailing, no extra margin inside `.text-button`).
- Replaced glyphs with `<ng-icon>`:
  - Season timeline: "Current round" uses `lucideLocateFixed`; completed round nodes use `lucideCheck`.
  - External links ("Official URC source", "Open Superbru"): `lucideExternalLink`.
  - "Watch video" (duty card, captain page): `lucidePlay`.
  - In-app links ("Duty details", "League duties", notification flag actions, "Save profile"/"Enter the clubhouse"): `lucideArrowRight`.
  - Match centre "Try again": `lucideRotateCcw`.
  - Profile team picker check mark: `lucideCheck`.
- Notification action strings no longer contain "→"; the icon is added in the template.
- `apps/web/CLAUDE.md` records the link icon convention.

No emoji remain in `apps/web/src`. Typographic quotes and the "·" separator were kept.

## Checks run

- `npm run build`: passed, no warnings (run with Node 24; the container's Node 22.22.2 is below the CLI minimum).
- `npm test -- --watch=false`: 10 files, 32 tests passed.
- `npx playwright test` with the preinstalled Chromium: 15 passed.
- Screenshots of the timeline, home, more, profile and notification flag checked on desktop.

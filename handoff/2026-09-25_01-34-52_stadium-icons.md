# Stadium icons

Recorded on 2026-09-25 in Africa/Johannesburg time. Paths are relative to `apps/web`.

## Request

Map each icon in the supplied URC 2026-27 stadium asset pack to its stadium in place of the generic stadium icon, keeping the generic icon only as a fallback.

## Completed changes

1. **Assets.** The 20 transparent 1254 px PNGs were trimmed to their drawing, padded square and saved as 256 px WebP in `public/assets/images/stadiums/` (600 KB total, down from 15 MB). `sources.json` records the source and the venue each file belongs to.
2. **Mapping.** `core/competition/stadiums.ts` now stores a country and an icon per venue, keyed by the venue names used in the fixture snapshot (`10bet Ellis Park`, `Hampden Park` and so on). New `stadiumIcon(venue)` sits beside `stadiumCountry(venue)`.
3. **Match hero.** The footer shows the venue's icon (64 px desktop, 52 px phone). The previous inline SVG is shown for unknown venues ("Venue to be confirmed") and if the icon fails to load.
4. **Preloading.** `matchArtwork()` includes the stadium icon, so the hero still swaps a matchup in one frame.
